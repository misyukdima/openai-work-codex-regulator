# Task classification 0–4

**Version:** 1.1  
**Status:** normative

## Class 0 — preparation

No agentic run needed.

Examples:

- prompt creation;
- report review;
- handoff;
- quota decision;
- deciding Work vs Codex.

Preferred surface: CHAT.

## Class 1 — light

One page/source or one file. Narrow, reversible, easy validation.

Examples:

- verify one live page;
- extract one small public fact set;
- edit one isolated config/document;
- run one bounded technical check.

## Class 2 — medium

Several sources or related files, one clear module/gate.

Examples:

- fresh buyer-demand search across 3–5 surfaces;
- one repo module change with tests;
- one structured report from multiple sources.

## Class 3 — heavy

Long/multi-source, multi-module, significant context or multiple agents.

Examples:

- broad research with many primary sources;
- large refactor;
- complex multi-artifact deliverable;
- long Work session involving several connected apps.

## Class 4 — critical

Any of:

- money/payment/purchase;
- external publication/message/form submission;
- customer/personal data;
- credentials/secrets;
- auth/permissions;
- production server/network/DNS/VPN/certificates;
- migration/deletion;
- irreversible or reputation-significant actions.

Class 4 applies even if the task touches one file or one button.

Read-only class 4 stays read-only until a separate bounded mutation approval exists.
